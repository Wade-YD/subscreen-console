# 副屏控制台 (Windows Subscreen Console)

给外接 / 便携显示器做的轻量控制台：**触摸开关 + 亮度调节 + 色彩调节**。pywebview 界面，Windows API 全部经 Python 标准库 ctypes 直调，第三方依赖仅 pywebview（界面）与 pystray/Pillow（托盘，托盘不可用时自动降级为热键唤出）。

> **ARZOPA 便携屏实测适配**——触摸开关 + 伽马调光全链路在其上跑通（详见下文「实测案例」）。其他品牌的触摸屏、支持 DDC/CI 的显示器同样适用，见「适配你自己的屏」。

起因：便携屏普遍没有官方的触摸开关；亮度/色彩想走 DDC/CI 时，很多廉价便携屏固件根本不响应。本工具对触摸用「禁用/启用 HID 数字化器」思路，对亮度/色彩用「伽马 LUT」兜底，并在屏幕支持 DDC/CI 时自动升级为硬件级。

## 功能

| 功能 | 原理 | 权限 |
|---|---|---|
| 触摸开关（按屏） | `pnputil` 禁用/启用对应触摸数字化器 HID 设备 | 每次切换弹一次 UAC |
| 亮度（幂曲线调光） | DDC/CI (VCP 0x10) 或软件伽马 LUT，启动时自动选择 | 免管理员 |
| 色温（2000–6500K 连续调节） | Tanner Helland 黑体算法 → 通道增益，与亮度合成同一条 LUT | 免管理员 |
| 对比度 | DDC/CI (VCP 0x12)，仅 DDC 可用时出现 | 免管理员 |
| 深度调光解禁（下限 1%） | 一次 UAC 写 `GdiIcmGammaRange` 注册表键（DisplayCAL 同款做法） | 单次 UAC |
| 多显示器切换 | 下拉选择目标屏，默认非主屏 | 免管理员 |
| 托盘常驻 / 开机自启 / 关窗最小化 | pystray + HKCU Run 键 | 免管理员 |
| 全局热键 | `RegisterHotKey`：`Ctrl+Alt+↑/↓` 亮度±10、`←/→` 色温锚点、`M` 触摸开关、`Q` 显隐面板 | 免管理员 |
| 夜间自动暖色 | NOAA 简化算法算日出日落，到点 10 步渐变到夜览色温 | 免管理员 |

## 快速开始

```bat
pip install -r 控制台\requirements.txt
控制台\启动控制台.bat
```

- 要求：Windows 10 2004+ / 11、Python 3.8+、WebView2 运行时（Win11 自带）
- 关闭窗口 = 最小化到托盘（托盘菜单"退出"才是真退出）；`--hidden` 参数可静默启动
- 零依赖备选：根目录 `TouchPanel.ps1`（v1 触摸开关面板，WPF）不需要 Python，双击 `启动面板.bat` 即用

## 调光模型（软件伽马模式）

Windows 对无特权进程的 `SetDeviceGammaRamp` 有两条实测约束：**单通道峰值 `out[255] ≥ 32768`**，且**陡曲线不允许峰值缩水**（幂指数 >4 拒绝；峰值打折的陡曲线也拒绝）。据此：

- 调光模型**双模式自适应**：
  - **线性模式**（解锁生效后）：`out = 设定值 × 灰阶` 等比压缩——白位=设定值（背光语义）、黑位不动、灰阶形状不变，**不动对比度**，亮度 1%–100% 全程可用
  - **幂曲线模式**（回退）：GDI 对 ramp 有每点偏离 identity 上限（约 ±50% 满幅）的校验——白位降到半程以下即触限被拒，只能白位恒满、压中间调，代价是暗部压缩的对比感损失；下限 25%（b=20–25 输出完全相同的 ramp 属死区）
  - **解锁后需重启 Windows（或注销重登）才生效**：注册表键由 win32k 会话初始化读取；未重启的会话里面板会自动回退幂曲线（写入被拒即切），重启后面板自动用线性模式，无需任何操作
- 想调到 1%（接近全黑）：点面板"解锁深度调光"，一次 UAC 写 `HKLM\...\ICM\GdiIcmGammaRange=1` 后解除约束（单屏生效，DisplayCAL 等校色工具同款做法）
- 色温增益归一化后，暗通道同样受峰值约束——无特权时低色温的蓝通道被自动抬底保护，解禁后保留完整增益
- 每次写入都检查返回值，被拒时 UI 明示（绝不再假装调上了）；睡眠唤醒/切分辨率后系统会重置 LUT，面板 watchdog 每 10 秒比对补涂（±2 LSB 容差）
- **本面板独占目标屏的 gamma ramp**：请勿与 Windows 夜间模式 / f.lux 等校色软件同用（会互相覆写打架）
- 夜间自动暖色的日出日落默认按北京（39.9°N, 116.4°E）计算，其他地区可改注册表 `HKCU\Software\副屏控制台` 的 `state` 值中的 `lat`/`lon` 字段

## 适配你自己的屏

1. **触摸**：设备管理器 → 人体学输入设备 → "符合 HID 标准的触摸屏" → 详细信息 → 硬件 ID，把 VID/PID 填进 `控制台/main.py` 顶部的 `CFG['touch_hwid']`
2. **亮度/色彩**：无需配置，启动时自动探测目标屏的 DDC/CI 能力：可用 → 硬件级（亮度/对比度）；不可用 → 伽马 LUT 软件级（亮度/RGB 增益）
3. **目标屏**：默认取非主屏；单屏环境退回主屏（`display.pick_target`）

触摸候选的过滤很严格：设备硬件 ID 必须含数字化器用法页（`UP:000D`）才入选，避免误控同芯片上的厂商自定义接口——实测某沁恒芯片的屏会同时枚举出 MI_00 触摸 + MI_01 厂商通道两个设备。

## 实测案例（某 ARZOPA 便携屏，DP/USB-C 连接，固件 V6.385）

- **完全不支持 DDC/CI**：OSD 恢复出厂后重测，所有 VCP 码（含能力串）仍返回错误 31——廉价便携屏的常见坑
- 触摸芯片为沁恒 (VID_1A86)：禁用 MI_00 即关触摸；关闭状态同口重启保持、换 USB 口自动恢复
- 伽马方案工作良好：写入读回验证通过，睡眠唤醒后面板每 10 秒自动补涂

## 工作原理 & 注意

- **触摸**：Windows 没有按屏关触摸的设置项，但每块触摸屏是一个独立 HID 设备，禁用即关。关闭状态绑定"设备实例"：换 USB 口后系统视为新设备，触摸会自动恢复
- **伽马模式**：调节的是显示 LUT（夜间模式同原理），立即生效但属软件调光——拉很低有轻微对比损失，且不能超过 100%（无法"增亮"）；睡眠唤醒/切分辨率后系统会重置 LUT，面板 watchdog 每 10 秒比对补涂
- **DDC 模式**：调节直达显示器，与物理按键等效
- 状态持久化在注册表 `HKCU\Software\副屏控制台`，不写任何文件；关闭面板后当前伽马保持生效，想完全还原就开面板点"恢复默认"
- 面板打不开时的手动兜底：设备管理器 → 人体学输入设备 → 触摸屏 → 右键 启用/禁用

## 免 UAC（可选，针对 v1 触摸面板）

注册一个以最高权限运行的计划任务，之后 `schtasks /Run` 触发即可不再弹 UAC：

```cmd
schtasks /Create /TN TouchToggle /TR "powershell -NoProfile -ExecutionPolicy Bypass -WindowStyle Hidden -File <项目目录>\TouchPanel.ps1" /SC ONCE /ST 23:59 /RL HIGHEST /F
schtasks /Run /TN TouchToggle
```

```
├─ 免UAC启动.bat          v1 免 UAC 启动（需先注册上面的计划任务）
└─ 控制台/               v2 主程序（pywebview）
   ├─ main.py            入口 + js_api + 注册表持久化 + 托盘/热键/自启/夜间暖色
   ├─ display.py         显示器枚举 / 幂曲线伽马 LUT + 开尔文色温 / DDC/CI（ctypes 直调）

   ├─ requirements.txt   pywebview / pystray / pillow
   ├─ ui/index.html      界面
   └─ 启动控制台.bat      启动器
```
